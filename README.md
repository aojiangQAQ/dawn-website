# dawn-website · 曙光开服器官网

曙光开服器的静态展示网站，使用原生 HTML、CSS 和 JavaScript。

作者：**aojiangQAQ（鳌江）**

本仓库只包含官网页面，不包含开服器桌面应用、服务器管理后端或模型调用代码。页面中的仪表盘、服务器实例、AI 对话、插件市场和安全扫描界面均为展示用示例；菜单切换和控制台动画不会执行实际开服操作。

## 本地预览

直接在浏览器打开 `index.html`，无需安装依赖或构建。也可以使用已有的静态文件服务器预览。

页面通过 Google Fonts 加载 Inter 字体；离线时会使用 CSS 中的系统字体回退。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 产品介绍、展示界面、下载与项目链接 |
| `style.css` | 页面样式、响应式布局和动画 |
| `script.js` | 展示菜单切换、滚动效果与模拟控制台输出 |

## 部署与维护

将 `index.html`、`style.css` 和 `script.js` 上传到同一个静态站点目录，设置 `index.html` 为首页即可；无需 Node.js、数据库或后端进程。

更新官网时：

1. 在 `index.html` 中更新产品文案、下载地址和源码链接。
2. 在 `script.js` 中维护模拟控制台内容，在 HTML 中维护其他展示数据。
3. 保持样式和脚本的相对路径不变，检查页面内的锚点及外部链接。

产品下载、源码、反馈和许可链接目前指向 `aojiangQAQ/dawn-server-launcher`；访问范围和发布内容由对应项目维护。页尾的 MIT 许可链接指向开服器项目，本仓库未附带单独的 `LICENSE` 文件。

## 公开内容

页面未配置后台、统计脚本或真实 API 凭据；模型地址和遮蔽后的 API Key 为静态展示内容。新增图片、示例日志或部署配置时，应避免提交真实密钥、私人服务器地址及本机环境文件。
